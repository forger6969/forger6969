## Featured Project — WeWatch

> Social online cinema — watch movies together, perfectly in sync

**Architecture:** 7 independent microservices (auth, user, content, watch-party, battle, notification, admin)

- Real-time video sync engine — ±2s accuracy, heartbeat + drift correction
- Democratic buffering — all viewers pause when one buffers, resume together
- JWT RS256 auth with refresh rotation
- Bull job queues for async push notifications
- Elasticsearch for content discovery
- Deployed on Railway with MongoDB Atlas
